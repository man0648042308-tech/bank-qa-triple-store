# 独立复现训练

## 1. 为什么不是“再读一遍源码”

阅读会产生熟悉感，但独立开发要求你在没有提示时主动回忆：输入是什么、数据放在哪里、条件怎样组合、输出是什么。因此训练采用四层闸门，不通过当前层就不把能力记为完成。

## 2. 四层证据

### A. 跟做证据

- 自己输入命令，不由AI代运行；
- 能指出当前目录；
- 能解释命令中的`uv run`、`python -m`、`--offline`，以及为什么它不能和`--online`同时使用；
- 保存终端输出和一次错误记录。

### B. 半闭卷证据

只看函数名、参数和测试，不看实现，完成：

1. 创建`must_clauses`与`filter_clauses`；
2. 把关键词、价格、品类放入正确位置；
3. 设置高亮、size和排序；
4. 运行测试，根据第一条失败修复。

允许查看`learning/starter/README.md`，不允许复制生产答案。

### C. 闭卷证据

只看`learning/closed_book/README.md`的需求合同，从空文件实现最小版。闭卷目录故意不提供答案。

### D. 迁移证据

把“银行产品”改成“招聘岗位”：

- `keyword`搜索岗位名称；
- 薪资范围进入`filter`；
- 城市进入精确过滤；
- 高亮岗位名称；
- Redis键加入求职者编号、最新画像指纹、岗位目录指纹、问题摘要和数据版本。

能迁移才说明理解了结构，而不是只记住银行示例。

## 3. 六段学习安排

### 19:00～19:30：带着做

1. 打开VS Code项目目录。
2. 运行离线测试。
3. 运行离线主程序。
4. 在纸上画出“最新画像→问题分类→领域外直接拒答；推荐/事实→画像与目录缓存键→未命中→ES/Neo4j→RRF→事实定位产品/推荐硬过滤→回答→缓存”。

结果证据：终端输出与一张手绘流程图。

### 19:30～20:20：基础概念和最小示例

只读：

- `exercise05/query_builder.py`
- `tests/test_exercise05_query.py`
- `docs/02_核心代码逐行逐词讲解.md`

修改一个参数，先预测查询体，再运行确认。

### 20:30～21:30：跟随复现指南实现

进入`learning/starter`，按照TODO实现查询体。每完成一个条件就运行一次验证，不要一次写完所有内容。

### 21:40～22:40：合上资料重新实现

进入`learning/closed_book`，只看需求合同，从空文件重新写。卡住超过10分钟，可以只看函数签名，不能看函数体。

### 22:40～23:10：测试、调试、错误记录

故意制造一个错误：

- 把`is not None`改成直接布尔判断；或
- 把`products`列表当成字典访问；或
- 临时填错数据库端口。

保存原始错误，定位、修复、回归，填入错误记录模板。

### 23:10～23:25：口述复盘

不看稿录音回答：

1. `must`和`filter`有什么区别？
2. `_source`与`highlight`有什么区别？
3. 为什么必须先读最新画像，再查Redis？
4. 为什么缓存键除了客户编号还要有画像指纹和产品目录指纹？
5. 为什么风险过滤不能交给LLM？
6. 事实问答与个性化推荐有什么区别？
7. “今天天气如何”为什么必须返回空产品结果？
8. 三库为什么只绑定VM回环并通过SSH隧道访问？
9. 无、错、正确`X-API-Key`分别应得到什么状态码？

## 4. 闭卷评分

| 维度 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 输入合同 | 不知道参数 | 看提示能说 | 独立写出并解释 |
| 查询结构 | must/filter混淆 | 能修改 | 独立构造 |
| 边界 | 忽略0和None | 提醒后修复 | 主动写测试 |
| 运行 | 不知道目录 | 复制命令成功 | 能解释并换参数 |
| 调试 | 只说报错 | AI帮助定位 | 独立从Traceback定位 |
| 口述 | 只能念稿 | 能说流程 | 能说原因和取舍 |

总分不到9分时，不进入更复杂框架；先补最低分项。没有实际提交时记录“未开始/无提交证据”，不能记录为能力失败。

## 5. 本次训练的停止条件

今晚最低闭环不是把所有文档看完，而是：

```text
离线版运行成功
+ 示例五半闭卷通过
+ 修复一个真实/故意错误
+ 9个问题口述完成
```

满足后停止，第二天再做真实三库闭卷启动，避免长时间低效浏览。
