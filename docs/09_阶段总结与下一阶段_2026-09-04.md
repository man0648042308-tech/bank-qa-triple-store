## 4. 等环境时可以完成的最小学习动作

只认识一条输入输出链，不要求现在重写完整问答工程。打开 VS Code 的“终端 → 新建终端”，确认终端类型是 PowerShell。

先进入工程：

```powershell
Set-Location "./Day37_Bank_QA_Homework"
```

`Set-Location` 是 PowerShell 的“切换当前文件夹”；后面的引号包住完整路径。成功后提示符中的路径应变成该工程。不要把终端提示符 `(base) PS ...>` 一起输入。

再运行：

```powershell
uv run --offline --no-sync python -m day37_bank_qa.main --offline --customer-id C001 --question "请推荐稳健产品" --top-k 3
```

逐词解释：

| 命令片段 | 这次做什么 |
|---|---|
| `uv` | 项目已有的 Python 环境管理工具 |
| `run` | 在项目环境中运行后面的程序 |
| 第一个 `--offline` | 交给 uv：这次不要联网下载依赖 |
| `--no-sync` | 交给 uv：直接用已有环境，不更新安装包 |
| `python` | 启动 Python 解释器 |
| `-m` | 按模块名运行程序，而不是输入一个 .py 路径 |
| `day37_bank_qa.main` | 对应 `./Day37_Bank_QA_Homework\src\day37_bank_qa\main.py` |
| 第二个 `--offline` | 交给我们的程序：用技术演示数据替身，不连接真实三库 |
| `--customer-id C001` | 选择技术演示客户 C001，其画像为 R1、可用金额5000元 |
| `--question "请推荐稳健产品"` | 把整句文字作为问题传入；引号保持文字是一个参数 |
| `--top-k 3` | 最多返回3个合规产品；不保证一定有3个 |

预期输出中有 `recommended_product_ids`，值为 `["P001"]`。本轮相同命令（增加只影响字节码缓存的 `-B`）已实测成功。

`P001` 是编号，`安心存款` 是名称，`R1` 是此技术演示产品的风险等级，`1000` 是起投金额。C001满足这三项；P002/P003/P004风险更高，P005已停售。商品相似或金额够，不代表一定可以推荐。

之后只把问题换成 `安心存款起投金额是多少？` 再运行。应看到事实回答，但 `recommended_product_ids` 为空，因为查询产品属性与推荐购买是两种不同请求。

现在只需能说明：我输入了哪个客户、问了什么、系统返回什么、是否用了真实数据库。后续闭卷示例由你写，AI不会把答案填进你的 closed_book。

如果你编辑了 .py 文件，先在 VS Code 按 `Ctrl+S` 保存，再回终端按回车执行命令。只输入终端命令无需另存为文件。
